# NetBox Terraform product module

This project contains the [Terraform][Terraform] product module to deploy the
[Netbox K8s charm][Netbox K8s charm] with its dependencies (`redis-k8s`, `s3-integrator`
and `oauth-external-idp-integrator`) and tie them together with `juju_integration`
resources.

The module uses the [Terraform Juju provider][Terraform Juju provider] to model
the bundle deployment onto any Kubernetes environment managed by [Juju][Juju].

## Module structure

- **main.tf** - Defines the Juju applications to be deployed and the integrations between them.
- **variables.tf** - Allows customization of the deployment including each charm's channel,
  revision and configuration.
- **outputs.tf** - Exposes the `models` and `metadata` of the product deployment.
- **terraform.tf** - Defines the Terraform and Juju provider versions.
- **modules/** - Charm modules for the dependencies bundled by this product module.

## Using the NetBox product module

Always pin the `?ref=` to a released tag or a commit hash: CC008 does not allow floating
references such as branches.

```text
module "netbox" {
  source = "git::https://github.com/canonical/netbox-k8s-operator//terraform/product?ref=tf-1.0.0"

  model_uuid = juju_model.my_model.uuid
}
```
